# กฎการสร้าง Insight (ตรวจย้อนกลับได้)
โค้ดอยู่ใน `dashboard/app.js` ฟังก์ชัน `buildInsights()` · ไม่ใช้บริการ AI ภายนอก · คำนวณใหม่ทุกครั้งตามตัวกรอง
แต่ละข้อมี: สิ่งที่พบ · ช่วงและขอบเขต · ผลกระทบ · สิ่งที่ควรตรวจหรือดำเนินการ · ทีมที่รับผิดชอบ · ปุ่มดูรายการรองรับ (drill-down ใช้ตัวกรองเดียวกัน)
จัดลำดับตามผลกระทบเป็นบาท (|ผลต่าง|) แสดงสูงสุด 5 ข้อ · ป้ายเขียว "ข้อเท็จจริงจากข้อมูล" / ป้ายส้ม "ประเด็นข้อมูล"

| กฎ | เงื่อนไข | ผลกระทบที่ใช้จัดลำดับ | กันการตีความผิด |
|---|---|---|---|
| R1 หน่วยที่ขับเคลื่อนยอด | หน่วย (บริษัท+แผนก) ที่ผลต่างเป็นบาทติดลบมากที่สุด และเป็นบวกมากที่สุด | |ผลต่าง| | ถ้าหน่วยมีวันที่ไม่พบรายการในช่วงใดช่วงหนึ่ง → จัดเป็น "ประเด็นข้อมูล" ส่งบัญชี/ไอที ไม่สรุปว่ายอดตก · สาเหตุหน้างานเขียนเป็นสมมติฐาน |
| R2 กลุ่มธุรกิจที่เปลี่ยนมากสุด | กลุ่มที่ |ผลต่าง| สูงสุด + แยกผลจากปริมาณ/ราคา/ส่วนอื่น | |ผลต่าง| | แยกผลจากปริมาณ/ราคาเฉพาะเมื่อปริมาณที่หน่วยชัดเจนครอบคลุม ≥80% ทั้งสองช่วง ไม่เช่นนั้นจะบอกว่าแยกไม่ได้ |
| R3 สัดส่วน Non-Oil | มียอด Non-Oil | |ผลต่าง Non-Oil| | แยก Amazon/7-Eleven/ค่าเช่า · ระบุว่า 7-Eleven เป็นค่าบริหาร · สัดส่วนยอดขายน้อยไม่ได้แปลว่ากำไรน้อย |
| R4 การกระจุกตัว | มีหน่วยมากกว่า 3 | 5% ของยอดรวม 3 อันดับแรก | ระบุว่าจัดอันดับตามยอดขาย ไม่ใช่ประสิทธิภาพ |
| R5 ความครบถ้วน | หน่วยที่บันทึกรายวันแต่มีบางวันไม่พบรายการ | ยอดช่วงเทียบของหน่วยเหล่านั้น | ไม่มีปฏิทินวันเปิด-ปิด จึงเป็น "รอตรวจสอบ" ไม่ฟันธงว่าข้อมูลขาด |
| R6 ลูกค้าที่ระบุตัวได้ | ลูกค้าที่ยอดลดลงมากที่สุด โดยไม่รวมบัญชีเงินสด/POS/โปรโมชัน/Amazon/Corporate-Prepaid/บัญชีลูกหนี้รายสถานี | |ผลต่าง| | แสดงความครอบคลุมของลูกค้าที่ระบุตัวได้ |

**สิ่งที่กฎเหล่านี้ไม่ทำ:** ไม่อ้างสาเหตุ (เช่น คู่แข่ง สินค้าขาด) · ไม่จัดอันดับผู้จัดการ · ไม่เสนอปิดสาขา/ลดคน/ลงทุน · ไม่สร้างคะแนนความมั่นใจ

## หน้า 5 · ลูกค้าค้าส่ง (ฟังก์ชัน `pageWholesale()`)
ข้อมูล: บรรทัดช่องทาง "ค้าส่ง" (config/channel_rules.csv) · ลูกค้า = ชื่อคู่ค้าที่ตัดช่องว่างแล้ว (รวมรหัสที่เปลี่ยน เช่น AR00C-021 → AR04C-021)
| ป้าย | เงื่อนไข |
|---|---|
| หยุดซื้อ | ซื้อครั้งล่าสุดก่อนช่วงที่เลือก และห่างจากวันเริ่มช่วงไม่เกิน 180 วัน · "ยอดที่เคยซื้อ" = เฉลี่ย 3 เดือนก่อนเดือนที่ซื้อครั้งสุดท้าย |
| หยุดซื้อนานแล้ว | ซื้อครั้งล่าสุดก่อนช่วงที่เลือกเกิน 180 วัน |
| ลูกค้าใหม่ | ซื้อครั้งแรกในช่วงที่เลือก |
| ลดลง / เพิ่มขึ้น | เปลี่ยน ≥ 20% และ ≥ 50,000 บาท เทียบช่วงเปรียบเทียบ |
| คงที่ | นอกเหนือจากข้างบน |
- ผลจากปริมาณ = (กก.ใหม่ − กก.เดิม) × ราคาเฉลี่ยเดิม · ผลจากราคา = (ราคาใหม่ − ราคาเดิม) × กก.ใหม่
- ช่วงหลังวันที่ของเอกสารค้าส่งล่าสุดจะไม่ประเมินลูกค้าหาย/ลด และขึ้นคำเตือน (บัญชีคีย์ค้าส่งเอง)
- ลูกค้าบางรายรับของเป็นรอบ เดือนที่ยอดต่ำอาจเป็นรอบส่ง · ข้อมูลไม่บอกสาเหตุ ทีมขายส่งต้องสอบถามลูกค้า
