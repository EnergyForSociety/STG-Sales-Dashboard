# รายการข้อมูลที่ต้องขอเพิ่ม

เรียงตามผลกระทบ · แต่ละข้อระบุว่าจะปลด KPI ใดในกรอบผู้บริหาร

## ก. ฝ่ายบัญชี / การเงิน

1. **สิทธิ์แพ็กเกจ Datawarehouse หรือ ERP ของ TRCloud** — API งบกำไรขาดทุนรายเดือน งบดุล และสต็อก ยังถูกจำกัด
   → ปลด: Profit และ Gross Margin ที่กระทบยอดกับบัญชีทุกเดือน ทั้งสามบริษัท (ไม่ต้องพึ่งไฟล์ P&L รายเดือน)
2. **P&L รายสถานีของ TWP** และของ STG/STP ย้อนหลังให้ครบปี (ตอนนี้มีเฉพาะ ก.ย.–ต.ค. 2569 ของ STG/STP)
   → ปลด: กำไรรายสถานีครบทั้งกลุ่มและเทียบรายเดือนได้
3. **Bank statement รายเดือนทุกบัญชี** (ยอดยกมา รับ จ่าย คงเหลือ) หรือสิทธิ์อ่าน Bank Statement ใน TRCloud ที่คืนรายการได้
   → ปลด: Cash · Cash Flow ตามฐานรับจ่ายจริง · การแยกเงินสดหน้าสถานี เงินฝาก และเงินโอนระหว่างสาขา/บริษัท
4. **ใบแจ้งยอดของผู้ให้บริการบัตร/แพลตฟอร์ม** (รอบ settlement และยอดที่โอนจริง)
   → ปลด: ยอดรอ settlement ที่กระทบยอดได้ แยกจากลูกหนี้ค้าส่ง
5. **รายการระหว่างบริษัท** (คู่ค้าในกลุ่ม เลขเอกสาร และยอด) เพื่อทำ elimination
   → ปลด: ยอดรวมกลุ่มที่เรียกได้ว่า "หลังตัดรายการระหว่างกัน" (ตอนนี้ต้องเรียกว่า "ก่อนตัดรายการระหว่างกัน")
6. **สถานะปิดบัญชีรายบริษัท/งวด** (เดือนใดปิดแล้ว)
   → ปลด: เลิกกำกับว่า "ผลเบื้องต้น" ในหน้าการเงิน

## ข. ฝ่ายปฏิบัติการ / สาขา

1. **กติกาการลงยอดภายในวันถัดไป (D+1)** และรายงานสาขาที่ยังไม่ลงยอดทุกเช้า
   → ปลด: ความน่าเชื่อถือของ MTD และผลงานเทียบเป้า (ตอนนี้บางสาขาค้างหลายวัน ดู coverage matrix)
2. **ทะเบียนสาขาที่มีวันเปิด วันปิด วันเปลี่ยนบริษัท และวันเปลี่ยนรูปแบบธุรกิจ**
   → ปลด: Same-store ที่แยก "สาขาเปิดใหม่/ปิด" ออกจาก "สาขาที่ยังลงยอดไม่ครบ" ได้จริง
3. **รายชื่อ AM–สาขา ที่เป็นแหล่งจริงแหล่งเดียว** และอัปเดตทุกครั้งที่ย้ายเขต
   → ปลด: ผลงานรายผู้จัดการเขตที่ตรงกับโครงสร้างปัจจุบัน
4. **ลิงก์รายงาน Power BI ที่ถูกต้อง** (ถ้าต้องการปุ่มเปิดจากหน้า Operation)
   → ปลด: ปุ่ม "ดูรายละเอียด Operation ใน Power BI" โดยเคารพสิทธิ์เดิม

## ค. ฝ่ายซ่อมบำรุง (Factorium)

1. **กรอกช่อง "วันที่คาดว่าจะเสร็จ" ให้ครบ** (ตอนนี้ 8 จาก 294 ใบงาน)
   → ปลด: อัตราส่งมอบงานซ่อมตามกำหนด และการคาดการณ์งานที่จะเลยกำหนด
2. **ใช้ช่อง "สถานะเครื่องจักรหยุด" ตามจริง** (ตอนนี้เป็น "ยังใช้งานได้" ทุกใบงาน)
   → ปลด: เวลาที่อุปกรณ์หยุดใช้งาน และผลกระทบต่อยอดขายของสาขานั้น
3. **ผูกเลขที่ PO กับใบงาน** (ตอนนี้อ้างถึงใน "วิธีการแก้ไข" เป็นข้อความ)
   → ปลด: ค่าใช้จ่ายต่อใบงาน ต่อสาขา และต่อประเภทอุปกรณ์
4. **ส่งไฟล์ส่งออก Factorium ทุกเดือนพร้อมรอบข้อมูลขาย** และยืนยัน map แผนกใหม่ใน `config/maint_departments.csv`
   → ปลด: การติดตามใบงานค้างแบบต่อเนื่อง ไม่ใช่ภาพนิ่งรอบเดียว

## ง. ฝ่ายขาย / พัฒนาธุรกิจ

1. **ทะเบียนโอกาสขาย (CRM)**: ชื่อ มูลค่า ขั้นตอน (stage history) วันที่เริ่ม–ปิด ผล Won/Lost และผู้รับผิดชอบ
   → ปลด: Pipeline · Win Rate · Sales Cycle
2. **นิยาม New Customers ที่ตกลงร่วมกัน** และ mapping ลูกค้าข้ามบริษัท (บัญชีเงินสดรวม สาขา นิติบุคคล กลุ่มลูกค้า)
   → ปลด: New Customers · การนับลูกค้าที่ไม่ซ้ำข้ามบริษัท
3. **ทะเบียนกลุ่มลูกค้า/พื้นที่ (segment)**
   → ปลด: Market Segment
4. **นิยาม CLV** (อายุลูกค้า ต้นทุนต่อลูกค้า อัตราคิดลด) ถ้าต้องการจริง
   → ปลด: CLV — ถ้ายังไม่มี จะไม่คำนวณและไม่เรียกยอดซื้อสะสมว่า CLV

## จ. ฝ่ายวิศวกรรม / โครงการ

1. **ทะเบียนโครงการ** (ชื่อ ประเภท บริษัท สาขา เจ้าของงาน วันเริ่ม–กำหนดเสร็จ สถานะ)
2. **Milestone แผน–ผลจริง–คาดการณ์** และสาเหตุงานล่าช้า
3. **งบอนุมัติรายโครงการ + การผูกรหัสโครงการกับ PO/ค่าใช้จ่าย/สินทรัพย์ใน TRCloud**
4. **ชั่วโมงจัดสรรและชั่วโมงทำงานจริงรายคน/ทีม**
5. **วันเปิดใช้งานจริงของสาขา/อุปกรณ์** เพื่อเทียบยอดก่อน–หลัง
   → ทั้งหมดนี้ปลดหน้า "โครงการและการส่งมอบ" ทั้งหน้า

## ฉ. ข้อมูลปีก่อน

1. **ยอดขายปี 2568 รายวัน/รายเดือน แยกสาขา–สินค้า** เข้าคลังข้อมูลเดียว (ตอนนี้ TRCloud มีเฉพาะรายการยกยอดลูกหนี้)
   → ปลด: YoY ครบทุกกลุ่มสินค้า ทุกบริษัท โดยไม่ต้องพึ่ง Excel หลายไฟล์ · และ Same-store แบบเทียบปีต่อปี

## ช. หน่วยและสินค้า

1. **ยืนยันค่าแปลง LPG รายสาขา/งวด** ถ้าต่างจากค่าตั้งต้น 1.85 ลิตร/กก. (เพิ่มแถวใน `config/lpg_factor.csv` พร้อมวันที่มีผลและผู้ยืนยัน)
2. **นิยามการแปลงแกลลอน/ขนาดบรรจุ** ของสินค้า Non-Oil ถ้าต้องการปริมาณรวม
3. **การจัดประเภทของ PT-POINT และน้ำดื่มฟรี** ที่ฝ่ายบัญชียืนยัน (บวก/ลบ และเป็นรายได้หรือส่วนลด/โปรโมชั่น)
4. **สินค้าที่ยัง "รอจัดประเภท"** ใน `config/product_rules.csv` — ให้บัญชียืนยันกลุ่มธุรกิจและว่านับเป็นยอดขายหรือไม่
