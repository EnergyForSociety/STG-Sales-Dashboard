# กฎแปลงหน่วย LPG และฐาน VAT

## 1. ที่มา

เจ้าของโครงการยืนยัน: กลุ่มซื้อ LPG เป็น**กิโลกรัม** ขายปลีกเป็น**ลิตร** · Power BI เดิมใช้ค่าแปลงตั้งต้น **1.85 ลิตร/กิโลกรัม** และค่านี้ปรับได้ตาม configuration
ค่าแปลงจึงไม่ถูกฝังในโค้ด แต่เก็บไว้ที่ `config/lpg_factor.csv` ไฟล์เดียว

## 2. โครงสร้างไฟล์ `config/lpg_factor.csv`

| คอลัมน์ | ความหมาย |
|---|---|
| `company` | `STG` / `STP` / `TWP` หรือ `*` = ทุกบริษัท |
| `station_id` | รหัสสถานีตาม `config/stations.csv` หรือ `*` |
| `product_id` | รหัสสินค้า หรือ `*` |
| `effective_from` / `effective_to` | ช่วงที่มีผล (`effective_to` ว่าง = ยังมีผล) |
| `factor` | ลิตรต่อกิโลกรัม (ตรวจช่วงสมเหตุสมผล 0.5–5 ตอน build) |
| `source` | แหล่งอ้างอิง เช่น "Power BI เดิมของกลุ่ม (ค่าตั้งต้น)" |
| `confirmed_by` / `confirmed_at` | ผู้ยืนยันและวันที่ยืนยัน |
| `note` | หมายเหตุ |

**การเลือกแถว**: แถวที่เจาะจงกว่าชนะแถวที่กว้างกว่า (บริษัท > สาขา > สินค้า) และต้องครอบคลุมวันที่ของเอกสารนั้น
**ประวัติ**: การเพิ่มแถวใหม่พร้อม `effective_from` ไม่เปลี่ยนผลย้อนหลัง เพราะเว็บเลือก factor ตามวันที่ของเอกสาร ไม่ใช่ค่าปัจจุบัน
**ไม่มีแถวที่ตรง** = ไม่แปลง (คืน `null`) และหน้าเว็บจะบอกว่ายังไม่แปลงกี่กิโลกรัม — ไม่เดาค่าเอง

## 3. สูตร

```
กก. → ลิตร        = กก. × factor
ลิตร → กก.        = ลิตร ÷ factor
บาท/กก. → บาท/ลิตร = บาท/กก. ÷ factor
```

ตัวอย่างทวนสูตร (เป็นวิธีคิด ไม่ใช่ราคาหรืออัตราภาษีที่ตรึงไว้):
ต้นทุน 24.64 บาท/กก. **รวม VAT 7%** และ factor 1.85 → ต้นทุนก่อน VAT ต่อลิตร = 24.64 ÷ 1.07 ÷ 1.85 ≈ **12.45 บาท/ลิตร**

## 4. ฐาน VAT

- ชุดข้อมูลเก็บ `before_vat` และ `vat` **แยกกันตามเอกสาร** ไม่ถอดหรือบวก VAT ซ้ำ
- ยอดขายและต้นทุนทุกตัวที่ใช้เทียบกันอยู่บนฐาน **ก่อน VAT** เสมอ
- ถ้าต้นทุนที่ได้มารวม VAT ให้หารด้วย (1 + อัตราภาษีของรายการนั้น) ก่อนแปลงหน่วย — อัตราภาษีอ่านจากรายการ ไม่ตรึง 7% ในโค้ด
- กำไรขั้นต้นต่อลิตร = ราคาขายก่อน VAT ต่อลิตร − ต้นทุนขายก่อน VAT ต่อลิตร
- Gross Margin % = กำไรขั้นต้น ÷ รายได้ขายก่อน VAT × 100

## 5. กติกาการใช้ในรายงาน

1. ทุกหน้าเก็บ**ปริมาณและหน่วยตามเอกสารต้นฉบับ** และไม่รวมลิตร กิโลกรัม ชิ้น ขวด แกลลอน เป็นยอดเดียว
2. ค่าแปลงใช้เฉพาะช่องที่เขียนกำกับว่า **"เทียบเท่าลิตร"** (ปัจจุบันคือ KPI บนหน้ากลยุทธ์) โดยแสดงแยกว่า "ลิตรตามเอกสาร" กับ "แปลงจากกิโลกรัมด้วย factor เท่าไร"
3. ค้าส่งอ่านหน่วยตามเอกสารจริง ไม่บังคับเป็นลิตรตามค้าปลีก
4. บรรทัดที่ `unit` ว่างแต่มี `main_unit` / `main_unit_quantity` — ระบบตรวจฐานปริมาณก่อน (`vol_ok = 2`) ไม่จับชื่อหน่วยหลักคู่กับ quantity โดยอัตโนมัติ
5. การแปลงแกลลอนหรือขนาดบรรจุอื่นยังไม่ทำ จนกว่าจะมีนิยามที่ยืนยัน

## 6. วิธีแก้ค่า

1. เพิ่มแถวใหม่ใน `config/lpg_factor.csv` (อย่าแก้แถวเดิม ถ้าต้องการเปลี่ยนค่าตั้งแต่วันหนึ่งเป็นต้นไป — ใส่ `effective_to` ของแถวเดิม แล้วเพิ่มแถวใหม่)
2. `python3 scripts/build_lpg.py` → ตรวจค่าและเขียน `data/lpg.json`
3. `node scripts/build_pages.js` → `node scripts/build-static.js --key <กุญแจนอก repo> --out site`
4. ค่าใหม่จะโผล่ในตาราง "กฎแปลงหน่วย LPG และฐาน VAT" บนหน้าสถานะข้อมูลทันที พร้อมผู้ยืนยันและวันที่มีผล
