# ตารางความพร้อมของ KPI ตามกรอบผู้บริหาร

สถานะเดียวกับที่แสดงบนหน้า **สถานะข้อมูล** ในเว็บ (คำนวณจากชุดข้อมูลจริง ไม่ได้พิมพ์ทิ้งไว้)
4 สถานะ: **ใช้ได้แล้ว** / **รอยืนยัน** (มีตัวเลขแต่ต้องให้เจ้าของข้อมูลรับรองก่อนใช้ตัดสินใจ) / **รอข้อมูล** (ยังไม่มีแหล่ง) / **ไม่เหมาะกับบริบท**

## A. Executive

| KPI | สถานะ | เหตุผล / แหล่งข้อมูล |
|---|---|---|
| Revenue (ยอดขายก่อน VAT หักใบลดหนี้) | ใช้ได้แล้ว | IV3 + CN3 รายบรรทัดของทั้งสามบริษัท · กันเอกสารซ้ำด้วย บริษัท+รายงาน+item_id |
| Profit | รอยืนยัน | มีกำไรรายสถานีจากไฟล์ P&L (ก.ย.–ต.ค. 2569) เฉพาะ STG/STP · API งบกำไรขาดทุนยังติดแพ็กเกจ Datawarehouse/ERP · ต้นทุนในรายงานขายบางบรรทัดเป็นศูนย์ จึงไม่ใช้เป็นกำไรจริง |
| Cash / Cash Flow | รอข้อมูล | รายงาน Bank Statement ไม่คืนรายการในช่วงที่ตรวจ · ยอดขายเงินสดไม่ใช่เงินสดคงเหลือ · ยอดทะเบียนธนาคารไม่ใช่เงินพร้อมใช้ |
| Pipeline | รอข้อมูล | ไม่พบเอกสาร lead ใน connection ที่ตรวจ · SO อย่างเดียวไม่ใช่ pipeline |
| New Customers | รอยืนยัน | ต้องตกลงนิยามก่อน — บัญชีเงินสดรวมไม่ใช่ลูกค้าหนึ่งราย และลูกค้าที่เพิ่งปรากฏในชุดข้อมูลอาจไม่ใช่ลูกค้าใหม่จริง |

## B. Sales

| KPI | สถานะ | เหตุผล / แหล่งข้อมูล |
|---|---|---|
| ยอดขาย ปริมาณ ราคาเฉลี่ย และ mix | ใช้ได้แล้ว | แยกน้ำมัน/LPG/NGV/Non-Oil และค้าปลีก/ค้าส่ง · ปริมาณรวมเฉพาะบรรทัดที่หน่วยตรงกับกฎสินค้า |
| ผลงานรายบริษัท สถานี ธุรกิจ สินค้า ช่องทาง | ใช้ได้แล้ว | หน้าธุรกิจและสินค้า · บริษัทและสถานี |
| ลูกค้าค้าส่ง ซื้อเพิ่ม/ลด/หยุด/เริ่มซื้อ | ใช้ได้แล้ว | หน้าลูกค้าค้าส่ง (เทียบช่วงต่อช่วงจากเอกสารจริง) |
| MoM | ใช้ได้แล้ว | เทียบช่วงยาวเท่ากันก่อนหน้า และเตือนเมื่อช่วงที่เลือกยังไม่จบเดือน |
| YoY | รอข้อมูล | ปี 2568 ใน TRCloud มีเฉพาะรายการยกยอดลูกหนี้ · ที่ใช้ได้ตอนนี้คือ LPG หน้าร้านและน้ำมัน STP จากไฟล์ Excel |
| Lead / Opportunity / Win Rate / Sales Cycle | รอข้อมูล | ต้องมี stage history, Won/Lost, วันที่เริ่ม–ปิด มูลค่า และผู้รับผิดชอบ |

## C. Finance

| KPI | สถานะ | เหตุผล / แหล่งข้อมูล |
|---|---|---|
| Gross Profit / Gross Margin รายสถานี | รอยืนยัน | ไฟล์ P&L รายสถานี ก.ย.–ต.ค. 2569 (STG/STP) · ยังไม่ครอบคลุม TWP และยังไม่กระทบยอดกับบัญชีทุกเดือน |
| ค่าใช้จ่ายดำเนินงานรายสถานี | รอยืนยัน | มาจากไฟล์ P&L ชุดเดียวกัน |
| ลูกหนี้ค้าส่งและอายุหนี้ | ใช้ได้แล้ว | `get_receivable_due` รายเอกสาร · แยกลูกหนี้ค้าส่งออกจากยอดรอ settlement |
| เจ้าหนี้และกำหนดจ่าย | ใช้ได้แล้ว | `get_payable_due` รายเอกสาร |
| ยอดรอ settlement จากบัตร/แพลตฟอร์ม | รอยืนยัน | แยกไว้แล้วในหน้าเงินทุนหมุนเวียน แต่ยังไม่กระทบยอดกับใบแจ้งยอดของผู้ให้บริการ |
| Cash Flow ตามฐานรับจ่ายจริง | รอข้อมูล | ต้องมี statement ธนาคารและการแยกโอนภายในกลุ่มออกก่อน · หน้าเงินทุนหมุนเวียนไม่ใช่ Cash Flow |

## D. Project

| KPI | สถานะ | เหตุผล |
|---|---|---|
| Project Status · Milestone · งานล่าช้าและสาเหตุ | รอข้อมูล | ไม่มีทะเบียนโครงการในแหล่งที่เข้าถึงได้ |
| งบอนุมัติ / PO / ค่าใช้จ่ายรับรู้ / สินทรัพย์ / เงินจ่าย | รอข้อมูล | ต้องผูกรหัสโครงการกับเอกสารใน TRCloud ก่อน จึงจะแยกสี่ฐานนี้ได้ |
| Resource Utilization | รอข้อมูล | ไม่มีชั่วโมงจัดสรร/ทำงานจริง — ไม่ใช้จำนวนใบงานหรือระยะเวลาเปิด–ปิดแทน |

## E. Strategic

| KPI | สถานะ | เหตุผล |
|---|---|---|
| Growth ตามบริษัท ธุรกิจ สินค้า ช่องทาง | ใช้ได้แล้ว | หน้ากลยุทธ์ · ใช้ตัวกรองเดียวกับทุกหน้า |
| Same-store growth | ใช้ได้แล้ว | เทียบเฉพาะหน่วยธุรกิจที่มีเอกสารทั้งสองช่วง |
| ผลจากเปิด/ปิดสาขา | รอยืนยัน | ทะเบียนสาขายังไม่มีวันเปิด–ปิดและวันเปลี่ยนบริษัท/ธุรกิจ · หน้ากลยุทธ์จึงแยกเป็น "มียอดเฉพาะช่วงใดช่วงหนึ่ง" แทนการสรุปว่าเปิดหรือปิด |
| Product/Business mix · Non-Oil contribution | ใช้ได้แล้ว | สัดส่วนคำนวณจากยอดก่อน VAT ตามตัวกรอง |
| การเติบโตลูกค้าค้าส่ง | ใช้ได้แล้ว | หน้าลูกค้าค้าส่ง |
| Market Segment | รอข้อมูล | ยังไม่มีทะเบียนกลุ่มลูกค้า/พื้นที่ที่ยืนยัน |
| Customer Lifetime Value | ไม่เหมาะกับบริบท | ยังไม่มีนิยามอายุลูกค้าและต้นทุนต่อลูกค้า · ยอดซื้อสะสมไม่ใช่ CLV |

## F. ปฏิบัติการ (ผลงานเทียบเป้า + ซ่อมบำรุง)

| KPI | สถานะ | เหตุผล |
|---|---|---|
| เป้า ผลจริง Achievement รายสาขา/AM/บริษัท/ธุรกิจ | ใช้ได้แล้ว | เป้าและการแบ่งเขตจากไฟล์ Operation · ยอด MTD จาก TRCloud (บางสาขาใช้ตัวเลข Excel) |
| ช่วงข้อมูลและความครบถ้วน | ใช้ได้แล้ว | Coverage matrix รายหน่วยบนหน้าสถานะข้อมูล |
| ปุ่มเปิด Power BI | รอข้อมูล | ยังไม่ได้รับลิงก์ที่ถูกต้อง — จะไม่สร้างลิงก์หรือฝังรายงานเอง |
| ใบงานค้าง · ค้างเกิน SLA · งานความปลอดภัยค้าง | ใช้ได้แล้ว | ไฟล์ส่งออกจากระบบ Factorium · SLA อ่านจากระดับความด่วนในใบงาน |
| เวลาเฉลี่ยแจ้ง→ปิดงาน | ใช้ได้แล้ว | จากช่อง "ระยะเวลาตั้งแต่แจ้งซ่อมถึงซ่อมเสร็จ (นาที)" เฉพาะใบงานที่มีเวลาครบ |
| การส่งมอบงานซ่อมตามกำหนด | รอข้อมูล | ช่อง "วันที่คาดว่าจะเสร็จ" ถูกกรอกเพียง 8 จาก 294 ใบงาน |
| เวลาที่อุปกรณ์หยุดใช้งาน (downtime) | รอข้อมูล | ช่อง "สถานะเครื่องจักรหยุด" ถูกบันทึกเป็น "ยังใช้งานได้" ทุกใบงาน |
| ค่าใช้จ่ายต่อใบงานซ่อม | รอข้อมูล | ใบงานไม่ได้ผูกเลขที่ PO ในระบบบัญชี (อ้างถึงในช่องวิธีการแก้ไขเป็นข้อความเท่านั้น) |
| คะแนนความเสี่ยงรวม | ไม่เหมาะกับบริบท | ซ้ำกับงานฝ่ายความเสี่ยง |

## G. Data Status

| KPI | สถานะ |
|---|---|
| แหล่งข้อมูล ช่วงข้อมูล เวลาดึง ความครบถ้วนรายหน่วย | ใช้ได้แล้ว |
| กฎแปลงหน่วย LPG และฐาน VAT พร้อมวันที่มีผล | ใช้ได้แล้ว |
| รายการรอตรวจสอบ (บัญชี/ไอที) | ใช้ได้แล้ว |
