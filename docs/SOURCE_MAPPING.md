## Mapping สถานี/หน่วยธุรกิจ (config/stations.csv)
- **แผนก (department) ของ TRCloud = หน่วยธุรกิจในสถานี** (warehouse ตรงกับ department ทุกบรรทัด ยกเว้น 13 บรรทัด) และอ้างอิงชื่อจาก master_Department.xlsx
- STG: แผนก 0002–0025 = สถานี LPG 15 แห่ง (ตรงกับทะเบียน) · 0008/0009/0010 = พระราม 5 (น้ำมัน PTT / Café Amazon / 7-Eleven) · 0022/0023 = พิบูลสงคราม (น้ำมัน PTT / Café Amazon) · 362 = ธุรกิจค้าส่ง LPG (ไม่ใช่สถานี) · 0000 = สำนักงานใหญ่
- STP: 0001 เจ้าปลุก, 0002 เขาจีนแล, 0004 สนามบินตาก, 0005 ตาก-ลำปาง, 0007 นครหลวง (ครบ 5 แห่งตามทะเบียน)
- TWP: IN = NGV ขาเข้า, OUT = NGV ขาออก, OIL = น้ำมัน PTT (ผูกกับสถานีขาเข้าตามทะเบียน "NGV + PTT OIL" — รอยืนยัน), 0000/ว่าง = ยอด NGV ขายลูกค้าที่ไม่ระบุขาเข้า/ขาออก
- **TWP มียอดขายน้ำมันจริง** (HSD B7/Premium) จึงไม่ได้จัดยอดทั้งบริษัทเป็น NGV
- สถานีหลัก 24 แห่ง: Café Amazon, 7-Eleven และแผนกน้ำมันของ TWP ใช้ `station_id` เดียวกับสถานีหลัก จึงไม่นับเป็นสถานีเพิ่ม
- STG 0018 รุ่งเรือง: อยู่ใน master แต่ไม่มีในทะเบียนและไม่พบยอดปี 2569 → แสดงเป็น "ไม่พบรายการ" ไม่ใช่ศูนย์
- STP 0003 ขาณุ, 0006 คลองขลุง: ขายกิจการแล้ว (คู่มือ POS) → ไม่แสดง

## ความสัมพันธ์กับ POS (จาก docs/PT-Database-Reference.md)
- API (ทุกเช้า ~07:00) อ่านบิลของเมื่อวานจาก PT_DEV แล้วสร้าง IV ต่อสาขาต่อวัน: ใบ "ลูกค้าเงินสด" (รวมเงินสด/บัตร/QR) + ใบ "Promotion PT" (ส่วนลดแต้ม) → LPG เข้า STG, น้ำมันเข้า STP
- ยอด TRCloud = ลิตรรวมทั้งวัน × ราคา ไม่ปัด ส่วน POS ปัดทีละบิล → ต่างระดับสิบบาท/วัน/สาขา เป็นเรื่องปกติ · เกณฑ์ที่เสนอ ±0.1% ต่อวันต่อสาขา
- Dashboard นี้ใช้ TRCloud อย่างเดียว ไม่ผสมยอดเงินจาก POS
